# onAI Суфлёр

Суфлёр для съёмки с Bluetooth-пультом. Держите стрелку — текст едет быстро, отпустили — идёт дальше в своём темпе.

Без регистрации и рекламы. Сценарии хранятся только в вашем телефоне.

Страница суфлёра: **https://onai.academy/suflyor/**

## Установка

### iPhone

1. Откройте в **Safari**: https://saint4ai.github.io/onai-teleprompter-app/
2. Нажмите «Поделиться» — квадрат со стрелкой вверх. В iOS 26 он спрятан в меню «⋯».
3. Выберите «На экран „Домой“» → «Добавить».
4. Запускайте суфлёр с иконки на экране «Домой», а не из Safari.

Получилось, если суфлёр открылся без адресной строки. После первого запуска он работает и без интернета.

### iPhone: приложение через IPA

Если нужен суфлёр отдельным приложением, а не через Safari, поставьте его своим обычным Apple ID. Платный аккаунт разработчика не нужен, но нужен компьютер (Mac или Windows) и кабель.

1. Скачайте на компьютер [onai-suflyor-ios.ipa](https://github.com/saint4ai/onai-teleprompter-app/releases/latest/download/onai-suflyor-ios.ipa).
2. Установите [Sideloadly](https://sideloadly.io) и подключите iPhone кабелем.
3. Перетащите IPA в Sideloadly, введите Apple ID и нажмите Start. Пароль вводится в стороннюю программу — надёжнее завести для этого отдельный Apple ID.
4. На iPhone: «Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика» → включить. iPhone перезагрузится.
5. «Настройки» → «Основные» → «VPN и управление устройством» → ваш Apple ID → «Доверять».

Получилось, если «onAI Суфлёр» открывается с иконки.

Ограничения Apple для бесплатного Apple ID: подпись действует 7 дней, потом приложение нужно переподписать, и таких приложений не больше трёх. Sideloadly переподписывает сам, если включить в нём автообновление, а iPhone и компьютер в одной Wi-Fi-сети. Без компьютера каждую неделю — [SideStore](https://sidestore.io): компьютер нужен один раз, дальше он обновляет подпись на самом iPhone и ставит IPA прямо из Safari.

### Android

1. Скачайте [onai-suflyor-android.apk](https://github.com/saint4ai/onai-teleprompter-app/releases/latest/download/onai-suflyor-android.apk) — последняя версия.
2. Откройте скачанный файл. Телефон спросит, можно ли ставить приложения из браузера, — разрешите.
3. Если Play Защита предупредит о неизвестном приложении, нажмите «Всё равно установить».

Нужен Android 7 или новее. Новая версия ставится поверх старой, сценарии сохраняются.

## Пульт

Подключите пульт в настройках Bluetooth телефона, как наушники. Отдельное приложение для пульта не нужно.

| Кнопка | Что делает |
|---|---|
| Центральная, Enter или пробел | Старт и пауза |
| ← и → | Медленнее и быстрее. Текст не останавливается |
| ↑ и ↓, короткое нажатие | Шаг назад и вперёд, показ продолжается |
| ↑ и ↓, удержание | Быстрая прокрутка, через 3 секунды ещё быстрее. Отпустили — текст едет дальше с прежней скоростью |

Если кнопка не срабатывает: «Настройки» → «Настройки горячих клавиш» → нужное действие → «Добавить привязку» → нажмите кнопку на пульте.

## Стеклянный суфлёр

Камера снимает через стекло, а текст отражается в нём задом наперёд. Чтобы он читался, включите отражение: «Настройки» → «Настройки отображения» → «Перевернуть по X по умолчанию».

## Если что-то не так

- **Не появляется клавиатура.** Пока пульт подключён, телефон считает его клавиатурой. Вставьте текст до подключения пульта или выключите пульт на время правки.
- **iPhone не видит кнопку пульта в окне назначения.** Значит, кнопка шлёт громкость или команды плеера, а их iPhone не передаёт веб-приложениям. Если у пульта есть переключатель режимов, смените режим.
- **iPhone: экран гаснет во время показа.** На время съёмки: «Настройки» → «Экран и яркость» → «Автоблокировка» → «Никогда».
- **iPhone: пропали сценарии.** У Safari и у иконки на экране «Домой» раздельная память. Открывайте суфлёр всегда с иконки.

## Приватность

Нет аккаунтов, аналитики и рекламы. Сценарии не покидают телефон. Android-версия не запрашивает доступ в интернет. Веб-версия загружается с GitHub Pages, а потом работает без сети.

## Для разработчика

- Основа — [TiefPrompt](https://github.com/Tiefseetauchner/tiefprompt) (MIT, © Lena Tauchner). Доработки onAI — в ветке `onai`.
- Точка входа — `lib/main_foss.dart`. Flutter закреплён подмодулем `.flutter`.
- Сборки — GitHub Actions: `onai-apk.yml` собирает APK и гоняет тесты, `onai-web.yml` собирает веб-версию и публикует её на Pages.
- APK из CI подписан одноразовым ключом. В релиз идёт файл, переподписанный ключом onAI, — иначе обновление не встанет поверх.
- В каждый релиз загружайте копию APK под именем `onai-suflyor-android.apk` и IPA из `onai-ios.yml` как `onai-suflyor-ios.ipa`: на них ведут лендинг onai.academy/suflyor и README.
- Локально: `.flutter/bin/flutter test`, `.flutter/bin/flutter build web -t lib/main_foss.dart --no-web-resources-cdn`.
